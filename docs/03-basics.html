실습 환경: course-linux 컨테이너 준비: 0장의 예제 파일

학습 목표: 파일을 찾으려면 현재 위치와 경로를 확인합니다. 실행하려면 필요한 권한도 확인합니다.

경로는 파일의 주소입니다

주소를 처음부터 쓰면 절대 경로, 지금 있는 곳을 기준으로 쓰면 상대 경로입니다. pwd는 “나는 지금 어디에 있지?”, ls는 “여기 무엇이 있지?”를 확인합니다.

[실습] 따라 하기 · 위치를 바꿔 같은 파일 읽기

실습 환경: course-linux 컨테이너. 호스트에서 docker start -ai course-linux로 들어옵니다.

cd "$HOME/linux-server-lab"
pwd
ls
cat input/samples.tsv
cd output
cat input/samples.tsv
cat ../input/samples.tsv
cd ..
명령 한 줄씩 해석하기
명령 또는 부분 하는 일
cd "$HOME/linux-server-lab" 뒤의 경로로 현재 작업 위치를 옮깁니다. $HOME은 현재 환경의 홈, ..는 한 단계 위 폴더입니다.
pwd 현재 작업 중인 폴더의 절대 경로를 출력합니다. 파일을 찾기 전에 내 위치를 확인합니다.
ls 파일이나 폴더를 확인합니다. -l은 권한·소유자 등 상세 정보, -d는 폴더 내부 대신 폴더 자체, -h는 크기를 읽기 쉬운 단위로 보여줍니다.
cat input/samples.tsv 지정한 파일 내용을 읽어 출력합니다. /로 시작하면 절대 경로, ../는 상위 폴더를 기준으로 찾습니다.
cd output 뒤의 경로로 현재 작업 위치를 옮깁니다. $HOME은 현재 환경의 홈, ..는 한 단계 위 폴더입니다.
cat input/samples.tsv 지정한 파일 내용을 읽어 출력합니다. /로 시작하면 절대 경로, ../는 상위 폴더를 기준으로 찾습니다.
cat ../input/samples.tsv 지정한 파일 내용을 읽어 출력합니다. /로 시작하면 절대 경로, ../는 상위 폴더를 기준으로 찾습니다.
cd .. 뒤의 경로로 현재 작업 위치를 옮깁니다. $HOME은 현재 환경의 홈, ..는 한 단계 위 폴더입니다.
$HOME 현재 셸 환경의 홈 폴더입니다. 호스트와 컨테이너에서 다른 경로일 수 있습니다.

output 안에서 input/samples.tsv를 읽으면 실패합니다. 현재 위치에 input 폴더가 없기 때문입니다. ..는 한 단계 위입니다. ../input/samples.tsv는 성공합니다.

PATH는 데이터 파일의 주소와 다릅니다

PATH는 컴퓨터가 명령 프로그램을 찾는 폴더 목록입니다. wc 명령의 위치를 찾는 것과 samples.tsv 위치를 찾는 것은 다른 일입니다.

command -v wc
명령 한 줄씩 해석하기
명령 또는 부분 하는 일
command -v wc 해당 명령을 어디에서 찾았는지 보여줍니다. PATH의 프로그램 검색과 데이터 파일의 경로 찾기는 별개입니다.

권한은 파일을 사용할 수 있는 허가입니다

r은 읽기, w는 쓰기, x는 실행입니다. 파일 소유자·그룹·다른 사용자마다 허가가 다를 수 있습니다. 디렉터리의 x는 그 경로에 들어가거나 통과하는 권한입니다.

[실습] 따라 하기 · 내 스크립트의 실행 권한

printf '#!/bin/sh\necho hello\n' > scratch/hello.sh
chmod u-x scratch/hello.sh
ls -l scratch/hello.sh
./scratch/hello.sh
chmod u+x scratch/hello.sh
./scratch/hello.sh
명령 한 줄씩 해석하기
명령 또는 부분 하는 일
printf '#!/bin/sh\necho hello\n' > scratch/hello.sh 지정한 형식으로 글자를 출력합니다. \n은 줄바꿈, \t는 탭, %s는 뒤에 전달한 값을 넣는 자리입니다.
chmod u-x scratch/hello.sh 파일의 권한을 바꿉니다. u-x는 소유자의 실행 권한 제거, u+x는 추가입니다. 755는 소유자 읽기·쓰기·실행과 나머지 읽기·실행, 600은 소유자만 읽기·쓰기입니다.
ls -l scratch/hello.sh 파일이나 폴더를 확인합니다. -l은 권한·소유자 등 상세 정보, -d는 폴더 내부 대신 폴더 자체, -h는 크기를 읽기 쉬운 단위로 보여줍니다.
./scratch/hello.sh 현재 폴더를 기준으로 스크립트를 직접 실행합니다. ./가 경로를 지정하고, 파일에는 실행 권한이 필요합니다.
chmod u+x scratch/hello.sh 파일의 권한을 바꿉니다. u-x는 소유자의 실행 권한 제거, u+x는 추가입니다. 755는 소유자 읽기·쓰기·실행과 나머지 읽기·실행, 600은 소유자만 읽기·쓰기입니다.
./scratch/hello.sh 현재 폴더를 기준으로 스크립트를 직접 실행합니다. ./가 경로를 지정하고, 파일에는 실행 권한이 필요합니다.
> 경로 표준 출력을 파일에 저장합니다. 파일을 만들거나 덮어쓰지만 상위 폴더까지 만들지는 않습니다.
echo 글자 컨테이너 안에서 지정한 글자를 출력합니다. >가 있으면 그 출력을 파일에 저장합니다.

처음 직접 실행은 Permission denied, 권한을 준 뒤에는 hello가 기대됩니다. u+x는 소유자에게 실행 허가를 추가한다는 뜻입니다. 같은 실습 파일은 덮어씁니다.

0장의 컨테이너는 root 사용자입니다. 실제 서버의 일반 사용자는 읽기·쓰기에 제한이 더 있습니다. 읽기 권한 오류의 일반 사용자 실습은 선택 자료에 있습니다.

[실습] 공백이 있는 경로 - 5분

실습 환경: course-linux 컨테이너. 폴더 이름에 공백이 있으면 따옴표로 묶어 한 경로임을 알려 준다.

cd "$HOME/linux-server-lab"
mkdir -p "scratch/space demo"
printf 'hello\n' > "scratch/space demo/note.txt"
cat "scratch/space demo/note.txt"
명령 한 줄씩 해석하기
명령 또는 부분 하는 일
cd "$HOME/linux-server-lab" 뒤의 경로로 현재 작업 위치를 옮깁니다. $HOME은 현재 환경의 홈, ..는 한 단계 위 폴더입니다.
mkdir -p "scratch/space demo" 뒤에 적힌 폴더들을 만듭니다. -p는 상위 폴더도 만들고, 이미 있는 폴더는 그대로 사용합니다.
printf 'hello\n' > "scratch/space demo/note.txt" 지정한 형식으로 글자를 출력합니다. \n은 줄바꿈, \t는 탭, %s는 뒤에 전달한 값을 넣는 자리입니다.
cat "scratch/space demo/note.txt" 지정한 파일 내용을 읽어 출력합니다. /로 시작하면 절대 경로, ../는 상위 폴더를 기준으로 찾습니다.
> 경로 표준 출력을 파일에 저장합니다. 파일을 만들거나 덮어쓰지만 상위 폴더까지 만들지는 않습니다.

hello가 기대 결과다. 마지막 경로에서 따옴표를 빼면 shell이 여러 인자로 나눌 수 있다. 변수로 경로를 사용할 때도 "$HOME", "$PWD"처럼 묶는 습관을 익힌다.

이 장의 정리

  • 파일을 못 찾으면 현재 위치와 경로를 먼저 확인한다.
  • 권한은 필요한 대상에 필요한 만큼만 부여한다.
