# 1. 컴퓨터 자원에 대한 이해

> **실습 환경:** course-linux 컨테이너
> **준비:** 0장 완료

**학습 목표:** CPU는 계산하고, 메모리는 작업 중인 자료를 놓고, 디스크는 파일을 보관합니다.

## 책상에서 일을 하는 모습으로 생각해 보기
| 컴퓨터 용어 | 책상에 비유하면 | 하는 일 |
|---|---|---|
| CPU | 일하는 사람 | 명령을 처리하고 계산합니다. |
| 메모리 RAM | 책상 위 작업 공간 | 지금 사용하는 자료를 올려 둡니다. |
| 디스크 | 서랍 | 파일을 오래 보관합니다. |

서랍이 크다고 책상 위 공간도 커지는 것은 아닙니다. 그래서 디스크가 넉넉해도 메모리가 부족할 수 있습니다. 프로그램이 느리면 계산 중인지, 파일을 읽거나 쓰느라 기다리는지도 생각해야 합니다. 파일 읽기·쓰기를 **I/O**라고 합니다.

코어는 CPU 안의 계산 단위입니다. 여러 코어는 여러 작업을 함께 처리할 수 있습니다. 스레드는 프로그램 안의 일하는 흐름입니다. 지금은 **“많은 일을 동시에 시키면 CPU와 메모리를 더 사용할 수 있다”**는 정도부터 이해하세요.

## [실습] 따라 하기 · 내 작업 공간의 자원 보기
**실습 환경:** 0장의 course-linux 컨테이너. 아직 들어오지 않았다면 호스트에서 `docker start -ai course-linux`를 실행하세요.
```bash
nproc
free -h
df -h .
```
| 명령 | 무엇을 보나요? | 처음에는 이 부분만 |
|---|---|---|
| nproc | 사용 가능한 것으로 보고되는 CPU 수 | 출력된 숫자 |
| free -h | 메모리 상태 | available: 사용할 수 있는 메모리 |
| df -h . | 현재 경로의 저장공간 | Avail: 여유, Use%: 사용 비율 |

숫자를 외우지 않아도 됩니다. “CPU·메모리·디스크는 다른 자원”임을 구분하세요. 컨테이너에서 보는 값은 PC 전체의 값이나 실행 제한과 다를 수 있습니다. 실제 서버에서는 관리자가 할당한 범위 안에서 작업합니다.

컨테이너 안의 `free -h`에 보이는 전체 메모리와 `--memory=512m`으로 지정한 내 한도는 다를 수 있습니다. [6장의 docker stats 기본 실습](06-process.html#docker-stats)에서 실제 사용량과 한도를 확인합니다.

## [실습] 반복 활동 · 숫자보다 자원의 종류 구분하기
**10분 · 관찰·비교 활동.** 앞의 자원 보기를 따라 한 뒤 진행합니다.

### 바꿔 보기
macOS의 활성 상태 보기 또는 Windows 작업 관리자를 열어 CPU·메모리를 찾아보세요. 컨테이너에서 본 화면과 항목 이름이 달라도 괜찮습니다. 각 화면에서 CPU·메모리·디스크 정보를 어디서 확인했는지 적습니다.

### 고쳐 보기
다음 설명 중 잘못된 부분을 찾아 바르게 말하세요.
- “디스크가 1 TB니까 메모리도 충분하다.”
- “서버 CPU가 많이 보이니까 나 혼자 전부 써도 된다.”
<details markdown="1"><summary>힌트 보기</summary>
책상 위 공간과 서랍은 다른 자원입니다. 공유 서버에는 다른 사용자도 있습니다.
</details>
<details markdown="1"><summary>[답지] 해설 보기</summary>
디스크는 파일 보관, 메모리는 작업 중 자료를 놓는 공간입니다. 둘은 별도로 확인합니다. 사용할 CPU는 보이는 전체 수가 아니라 할당받은 범위를 기준으로 합니다.
</details>

### 설명하기
짝에게 CPU·메모리·디스크를 책상 비유로 각각 한 문장씩 설명하세요. 어려우면 앞의 표를 보면서 말해도 됩니다.

## 확인 질문
“파일 저장 공간이 부족하다”는 오류에 CPU를 늘리면 해결될까요?
<details><summary>[답지] 해설 보기</summary>
아니요. 계산할 사람을 늘려도 서랍은 커지지 않습니다. 저장할 경로의 디스크 공간을 확인해야 합니다.
</details>

[더 자세한 자원 설명](deep-dive.html)은 나중에 읽어도 됩니다.

## 이 장의 정리

- CPU는 계산, 메모리는 작업 중 자료, 디스크는 파일 보관을 맡는다.
- 같은 서버의 자원을 다른 사용자와 공유한다.
