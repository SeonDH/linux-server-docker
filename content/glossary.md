# 핵심 용어 다시 보기
## 처음에는 한 문장으로 이해한다
| 용어 | 쉬운 뜻 | 관련 장 |
|---|---|---|
| CPU | 계산하고 명령을 처리하는 자원 | 1장 |
| 메모리 RAM | 작업 중 자료를 올리는 공간 | 1장 |
| 디스크·스토리지 | 파일을 보관하는 공간 | 1·5장 |
| I/O | 파일이나 장치에 읽고 쓰는 일 | 1·4장 |
| 디렉터리 | 파일을 담는 폴더 | 3장 |
| 경로 | 파일과 폴더를 찾는 주소 | 3장 |
| PATH | 실행할 명령을 찾는 폴더 목록 | 3장 |
| 권한 | 누가 읽고 쓰고 실행할 수 있는지의 허가 | 3장 |
| 프로세스·PID | 실행 중인 프로그램과 그 번호 | 6장 |
| 로그 | 실행 중 메시지와 오류를 남긴 기록 | 4·8장 |
| 이미지 | 도구와 필요한 파일이 준비된 원본 | 2장 |
| 컨테이너 | 준비된 이미지로 차린 개별 작업 자리 | 2장 |
| bind mount | 지정한 호스트 폴더를 컨테이너에 연결 | 7장 |
| 볼륨 | Docker가 관리하는 별도 저장공간 | 2장 |
| 호스트 | 여기서는 Docker를 조작하는 PC·WSL 환경 | 0·7장 |
| Docker CLI | 요청을 보내는 docker 명령 | 2장 |
| Docker Engine | 요청을 처리하고 컨테이너를 실행하는 엔진 | 2장 |
| Docker Desktop | PC에서 엔진과 Linux 환경을 준비하는 앱 | 0·2장 |
| 마운트 | 파일시스템 등을 특정 경로에 연결 | 5장 |
| OOM | 메모리 부족 | 메모리 실습 |
| SIF | Apptainer 등에서 쓰는 이미지 파일 형식 | 9장 |

## 자주 헷갈리는 쌍
- 이미지와 컨테이너: 준비된 도구 세트와 그 세트로 차린 개별 작업 자리다.
- 메모리와 디스크: 작업 중 공간과 파일 보관 공간이다.
- 한도와 사용량: 허용된 최대 범위와 실제 사용하는 양이다.
- 정지와 삭제: 멈춰 보관하는 것과 작업 공간을 없애는 것이다.
- 호스트 경로와 컨테이너 경로: 같은 파일을 연결해도 보이는 주소는 다를 수 있다.

모든 용어를 외우지 않아도 된다. 실습 중 헷갈릴 때 이 표에서 다시 확인한다.

## 명령에서 자주 보는 기호

| 기호 | 쉬운 뜻 |
|---|---|
| `.` / `..` | 현재 폴더 / 한 단계 위 폴더 |
| `./파일` | 현재 폴더에 있는 파일의 경로 |
| `$HOME` / `$PWD` | 현재 환경의 홈 폴더 / 현재 작업 폴더 |
| `$PATH` | 프로그램 이름을 찾을 폴더 목록 |
| `$변수` | 변수에 저장해 둔 값 사용 |
| `$?` | 바로 앞 명령의 종료 상태 |
| `$!` / `$$` | 방금 시작한 백그라운드 작업의 PID / 현재 셸의 PID |
| `$(명령)` | 명령을 실행한 결과를 그 자리에 넣기 |
| `>` / `2>` | 정상 출력을 파일에 저장 / 오류를 파일에 저장 |
| `2>&1` | 오류도 정상 출력과 같은 곳으로 보내기 |
| `&#124;` | 앞 명령의 출력을 뒤 명령의 입력으로 전달 |
| `&` | 작업을 백그라운드로 실행 |
| `;` | 앞 명령 다음에 이어서 실행. 앞의 성공 여부와 별개 |
| `&&` | 앞 명령이 성공했을 때만 다음 명령 실행 |
| `"경로"` | 공백 등이 있어도 하나의 경로로 전달 |
| `'명령 문자열'` | 호스트에서 변수 등을 먼저 풀지 않고 문자열 전달. `sh -c`에 전달하면 해당 셸이 명령을 해석 |

## 추가 진단 용어

- **캐시:** 다시 쓰기 쉽도록 잠시 보관한 데이터입니다. 화면마다 메모리 사용량에 포함하는 방식이 다를 수 있습니다.
- **inode:** 파일과 폴더의 정보를 관리하는 항목입니다. 공간이 남아도 이 항목이 부족하면 새 파일을 만들 수 없습니다.
- **quota:** 사용자나 그룹이 사용할 수 있도록 정한 저장공간·파일 개수 등의 한도입니다.
- **SIGKILL:** 프로그램이 정리할 기회를 주지 않는 강제 종료 신호입니다. 종료 코드 137의 원인은 메모리 부족 외에도 있을 수 있습니다.
- **스케줄러:** 공용 서버에서 작업에 사용할 자원을 배정하고 실행 순서를 관리하는 시스템입니다.
